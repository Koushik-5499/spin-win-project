⚡ Quick Firebase Connection Guide

Your application is currently running in Local Simulation Mode. You can test all features right now. When you're ready to connect to your live Firebase Cloud project:

  1. Open Firebase Console (console.firebase.google.com) and create a project.
  2. Enable Firestore Database in production mode.
  3. Enable Authentication with Email/Password sign-in and create an admin user.
  4. Copy your web app configuration into js/firebase-config.js.
  5. Deploy the Firestore security rules from firestore.rules.
